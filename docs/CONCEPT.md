# Pomodoro Atelier — 作り直しの骨格

v1 を作りながら見えてきたことだけを残し、それ以外(UI・設計・実装・言語)は白紙から組み直した。
ここには「残したもの」と「なぜその形にしたか」だけを書く。

## 使う人にとっての価値

**目の前のことに集中する。** ポモドーロの考え方そのままに、時間はタイマーに任せ、目の前の作業だけを見ていられること。ほかの価値はすべてこれを支える。

| 使う人の困りごと | 得られること | アプリがしていること |
| --- | --- | --- |
| 作業を始めても、画面のほかのものに目が行く | **気が散らない** | 始めると周りが退き、タスクと残り時間だけが見える |
| 時間が気になって、何度も時計を見てしまう | **時計を見張らなくていい** | 区切りを通知とチャイムで知らせる。閉じていてもメニューバーとミニタイマーに残り時間 |
| タイマーの数字が実感とずれていて信じられない | **使った時間を信じられる** | 一時停止・スリープ・終了していた時間は数えない。タスクを替えても時間はそれぞれに付く |
| 一日の終わりに、何をしていたか言えない | **一日の行き先が分かる** | 今日の帯、記録、直近の傾向 |
| 記録がどこへ行くか分からない | **記録は自分のもの** | 手元に保存し、書き出せる |

紹介ページと README は、この表の「得られること」を主語にして書く。

## コアなユーザーストーリー

1. **いま、ひとつのことに集中したい。** タスクを選んで始めるだけで、フォーカスと休憩のリズムが回る。
2. **途中で対象が変わっても、時間は正しく付いてほしい。** タイマーを止めずにタスクを切り替えられ、実際に使った時間がタスクごとに残る。
3. **今日、時間がどこへ行ったかを見たい。** 一日の帯・記録・傾向を、あとから確かめて直せる。
4. **画面を見ていなくても残り時間が分かり、操作できる。** メニューバー・ミニタイマー・通知。
5. **記録は自分のもの。** 手元に安全に保存され、持ち出せて、戻せる。

集中を助ける環境音はストーリー 1 の一部として扱う。

## v1 で見えたペインと、その骨格

| v1 で繰り返し直したこと | 根にあった原因 | v2 の答え |
| --- | --- | --- |
| 見込み描画・応答待ち・送り直し・終了時の同期保存 | タイマーはレンダラ、保存は main と、権威が二つあった | **タイマーも保存も main の一つのエンジンが持つ。** 画面は状態を描いて命令を送るだけ |
| スリープ・tick の飛び・強制終了で実働が狂う | 「予定終了時刻」を持ち、経過をそこから逆算していた | **終了時刻を持たない。** 経過 = 実働区間の合計。動いていなかった時間は区間から切り取るだけ |
| 正規化が肥大化(開始・終了・実時間・区間・タスク内訳の食い違い) | 同じ事実を五つの項目に重ねて保存していた | **記録は「誰のための、いつからいつまで」の区間の列だけ。** ほかは全部そこから導く |
| 削除の取り消しに位置の控え・付け直しが要った | 削除で記録からタスクを剥がしていた | **削除は印を付けるだけ。** 記録はタスクを指したまま、取り消しは印を外すだけ |
| 何を見るにもモーダルを開く | タイマー画面と記録が別世界だった | **「いま」に今日の帯を常設**し、過去は「ふりかえり」ひとつにまとめる |
| フロー中にベルが鳴って途切れる / 記録を直せない | 予定と記録が固定だった | **+5分の延長**、記録のタスク付け替え・削除 |
| 外部フォント・ビルドなしの巨大な app.js | 素の JS と DOM 手書き | **TypeScript + Preact + esbuild**、フォントはシステムのもの(オフラインで完結) |

## 設計の決まり

- `src/core` は純粋(Electron にも DOM にも時計にも依存しない)。`reduce(data, command, now)` がすべての変更の入口。
- 状態は妥当なものしか存在しない。外から来るもの(ファイル・IPC)は `decode` / reducer の入口で一度だけ検める。
- 読めなかった・壊れていたファイルは、退避するまで上書きしない。v1 のファイルには書き込まない(読むだけ)。
- フォーカスは「動いていなかった時間」を実働に数えない。休憩は席を離れていても進む。
