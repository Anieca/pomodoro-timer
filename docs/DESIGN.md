# デザインの理由

画面にあるもの、並び方、動き方の一つひとつについて「なぜ存在するのか」「なぜこの姿なのか」を書く。
理由を書けないものは置かない。書いたが弱いものは、末尾の「理由が弱いもの」に正直に並べる。

## 根にある原則

すべての判断は、この三つのどれかに帰着する。

1. **注意を一点に集める。** 集中のための道具が、注意を奪ってはいけない。いま必要なもの以外は黙らせる。消すのではなく、手を伸ばせば届く場所へ退かせる。
2. **時間を正直に扱う。** 実際に向き合った時間だけを、向き合った相手に付ける。画面の数字はすべてその記録から導いたもので、飾りの数字は出さない。
3. **操作の結果は、その場で見える。** 保存ボタンや確認ダイアログを挟まない。間違えても取り消せることで、確認の代わりにする。

## 全体

### 二つの画面(いま / ふりかえり)
- **なぜあるか**: 利用者の問いは二つしかない。「いま何に向き合うか」と「時間はどこへ行ったか」。問いの数だけ画面を置いた。
- **なぜこの姿か**: 最初の版では、記録・統計・タイムテーブル・設定がそれぞれモーダルだった。見るたびに「いま」が隠れ、行き来が重かった。問いごとに一枚へ統合し、上の帯のタブと ⌘1 / ⌘2 で切り替える。

### 「いま」の三列(左: タスク / 中央: タイマー / 右: 今日)
- **なぜこの並びか**: 左から右へ「選ぶ → 向き合う → 振り返る」と、使う順序に並べた。読む順序と使う順序を揃えている。
- **なぜ左右が同じ幅か**: タイマーの軸を常に窓の中心に通すため。左右の幅が違うと、周りが退いたときに主役を寄せ直す必要があり、押そうとしたボタンが動いてしまう(実際に起きた)。

### 色
- **なぜ無彩色が基本か**: 色は注意を引く。引く理由のある場所にだけ使うため、地は無彩色にした。
- **なぜ藍と緑青の二色か**: 状態が二つ(向き合う / 休む)だから。藍は沈静と集中、緑青は回復を連想させる。どちらも彩度を抑え、警告色には見えないようにした。
- **どこに置くか**: 状態を示す場所だけ。区分名、経過の線、向き合っているタスクの左の線、今日の帯の「いま」の点。

### 文字
- **なぜシステムの書体か**: OS の文字と馴染み、外部から何も読み込まずに済む(オフラインで完結する)。
- **なぜ残り時間だけが巨大で細いか**: 画面の主役は残り時間なので、大きさで階層を示す。太くすると叫んでいるように見えるので、細さで静けさを保つ。離れていても読める大きさが要る一方、視界の中で重くなってはいけない。

### 線と角
- **なぜ 1px の罫か**: 領域の境界がわかれば十分で、それ以上の線は情報を運ばない。
- **なぜ角をわずかに丸めるか**: 押せるものだと手触りでわかる程度にする。丸すぎると玩具に見える。

## いま

### 沈む(動き出すと空間が変わる)
- **なぜあるか**: 「始めた」ことを、操作の確認ではなく環境の変化として伝えるため。部屋の照明を落とすのと同じで、切り替わった空間そのものが集中の合図になる。
- **なぜ深い色か**: 明るさは刺激になる。色を落とすことで、画面が視界の中で主張しなくなる。原色で染めた版はガジェットのように騒がしかったので、明度と彩度を沈めた。
- **なぜゆっくりか(1.4 秒)**: ボタンの反応(0.2 秒前後)より明らかに遅くすることで、「押した結果」ではなく「空間が移ろった」と感じさせる。秒数そのものは目で合わせた値。
- **なぜ休憩は緑か**: 休憩も没入の一種(ちゃんと休む)なので沈ませるが、色で区別する。

### 退く(タスク・今日の帯・上の帯が消える)
- **なぜあるか**: 動いている間、一覧や帯は判断材料にならず、視界の端で注意を引くだけだから。
- **なぜ消さずに退かせるか**: 途中でタスクを切り替えたいことはある。端にポインタを寄せればその欄だけが戻るので、操作は失わずに視界からだけ消せる。

### 手が止まると操作も消える(2.6 秒)
- **なぜあるか**: 作業中は画面に触れない。その間ボタンを出しておく理由がない。最後に残るのは、何に向き合っているか・あとどれだけか・どこまで来たかの三つだけ。
- **なぜ 2.6 秒か**: 動画プレイヤーが操作を隠す間合い(2〜3 秒)に倣った。

### 一時停止で浮上する
- **なぜあるか**: 止めるのは、タスクを替える・休む・記録を見るなど周りが要るとき。止めた瞬間に周りが戻れば、止めることがそのまま「息継ぎ」になる。

### 区分名(フォーカス / 小休憩 / 長休憩 / 次は〜)
- **なぜあるか**: 数字だけでは、いまが集中の時間か休む時間かわからない。
- **なぜ小さく色付きか**: 文字で読むものではなく、色で一瞬わかればよい補助だから。

### 長休憩までの点
- **なぜあるか**: 長休憩はサイクルの区切りで、「あといくつで長く休めるか」は続ける動機になる。
- **なぜ点か**: 数を読むのではなく、埋まり具合を一目で掴めれば足りる。

### タスク名
- **なぜ数字の上か**: 「何に」が「どれだけ」より先にあるべきだから。目的のない残り時間には意味がない。
- **なぜ「タスクを決めずに集中」と出すか**: タスクを決めることを強制しないため(決めずに始めるのも正当な使い方)。薄い色で出し、決めていないことは静かに伝える。

### 残り時間(経過ではなく)
- **なぜ残りか**: ポモドーロは決めた長さへの約束で、知りたいのは「あとどれだけ」だから。

### 経過の線
- **なぜあるか**: 数字は正確だが、読まないとわからない。線は視界の端で「どこまで来たか」を掴ませる。数字が言葉なら、線は感覚。
- **なぜ消化した側が伸びるか**: 積み上がっていく時間のほうが、減っていく時間より励みになる。数字は残り、線は消化と、二つで両面を示す。
- **なぜ一本の線で、円ではないか**: 横長の大きな数字を円で囲むと正方形の領域が要り、主役の数字と場所を取り合う。線なら数字の下に下線として収まる。ミニタイマーの下端、Dock の進捗バーと同じ「伸びる線」になり、どこで見ても同じ読み方ができる。
- **なぜ数字と同じ幅か**: 数字と線を一つの塊として読ませるため。
- **なぜ目盛りも数字もないか**: 正確な値は上の数字が受け持つ。線に同じ情報を持たせると繰り返しになる(以前のテープは目盛りに残り分を書いていて、上の数字と重複していた)。

### 操作ボタン
- **なぜ主操作だけ塗りか**: 次にやることは常に一つ(始める / 一時停止 / 再開)。迷わせないよう、それだけを目立たせる。
- **なぜ「5分のばす」があるか**: 乗っているときにベルで切られるのは、ポモドーロの最大の副作用だから。延長幅を選ばせると判断が一つ増えるので、5 分に固定した。
- **なぜ「中断する」と「休憩を終える」で言葉が違うか**: 意味が違うから。フォーカスを途中でやめるのは中断(未完走として残る)、休憩を早めに切り上げるのは正当な選択。

### 環境音
- **なぜあるか**: 周囲の音を均すことで、聴覚からの割り込みを減らす。
- **なぜ動いている間だけ鳴るか**: 音そのものが「いまは集中の時間」という合図になる。止めれば止まる。
- **なぜ下に置くか**: 頻繁には触らないが、すぐ切りたい瞬間はある(電話・会話)。主役の軸の延長、いちばん遠い場所に置く。

### タスク一覧
- **なぜ並び順に意味があるか**: 終えたら次へ自動で移るとき、並びの下にあるものを選ぶ。並びは優先順位なので、ドラッグで並べ替えられる。
- **なぜ足したタスクにそのまま向き合うか**: 何も選んでいないときに足したものは、ほぼ確実にいまやるものだから。
- **なぜ向き合っているタスクに色の線が付くか**: 時間がどのタスクに付くかを示すため。色は区分名と同じで、「いま時間が流れ込んでいる先」と読める。
- **なぜ完了したものを畳むか**: いまには要らないが、間違えて終えたときは戻したいから。
- **なぜ名前変更・削除が触れたときだけ出るか**: めったに使わない操作で、常に並べるとすべての行が騒がしくなる。
- **なぜ削除に確認がないか**: 削除は印を付けるだけで、トーストから元に戻せるから。

### タスクの入力欄
- **なぜボタンがないか**: Enter で足せる。押せるのは入力があるときだけのボタンは、ほぼ使われない。
- **キーボードの案内はどこにあるか**: 一度覚えたら読まないものを常に出さない。タスクが一つもないとき(最初に開いたとき)の案内と、ボタンの説明(title)にだけ置く。

### 今日の帯
- **なぜ「いま」の画面にあるか**: 今日どれだけ向き合えたかを、ふりかえりを開かずに感じられるように。小さな前進が見えることが、次の一本を始める理由になる。
- **なぜ縦の時間軸か**: 一日を上から下へ読むのは、紙の手帳やカレンダーと同じ読み方だから。
- **なぜ休憩は線だけか**: 帯で見たいのは向き合った時間で、休憩はその間の呼吸。塗ると主役と競う。
- **なぜ見出しを押せないか**: ふりかえりへの入口は上の帯のタブに一本化した。押せるのに押せる見た目をしていない部品は、置かない。

## ふりかえり

### 一日の帯と記録の一覧を並べる
- **なぜ両方あるか**: 同じ記録の、違う読み方だから。帯は「どこに空白があったか」を空間で見せ、一覧は「何分、どのタスクに」を正確に見せて直させる。帯を押すと一覧の該当行が選ばれる。

### 記録の付け替え・削除
- **なぜあるか**: タスクを選び忘れて始めることは必ず起きる。記録が間違ったままだと統計が嘘になる。

### 直近の傾向
- **なぜ 7 / 30 / 90 日か**: 一週間のリズム、一か月の習慣、四半期の傾向という三つの時間尺度。
- **フォーカス時間**: 量の事実。
- **完走**: 約束を守った回数。
- **完走率**: フォーカスの長さが自分に合っているかの指標。低ければ長すぎる。
- **連続日数を出さない理由**: 毎日続けることを促すのはゲームの仕掛けで、休むことも正しい道具の価値観と合わない。
- **日ごとの棒**: 押すとその日へ移る。傾向から個別の日へ降りる入口。
- **時間帯**: 自分が向き合いやすい時間を知り、予定を組むため。
- **タスクごと**: 時間を何に使ったかの答え。

## 設定

- **なぜ右から出る板か**: 変更がその場で反映されるので、裏の「いま」が見えている必要がある。全面を覆うと、効いたかどうかがわからない。
- **なぜ保存ボタンがないか**: 変えたそばから効くので、保存という段階が要らない。
- **なぜ「長さ・流れ・音・データ」の順か**: 触る頻度の順。

## ミニタイマー・メニューバー・通知

- **なぜあるか**: 別のアプリで作業している間も、残り時間を知り、止められるように。
- **なぜミニタイマーをメニューバーから開くか**: 本体の窓に置くと、一日に一度触るかどうかの機能が常に一等地を占める。ミニタイマーが要るのは本体を見ていないときなので、本体の外にある入口(メニューバー)が正しい場所。
- **ミニタイマーの中身が数字とタスク名と再生ボタンだけなのは**: 小窓で要るのは「あとどれだけ」「何に」「止める」の三つだけだから。
- **メニューバーの左クリックが開始 / 一時停止なのは**: もっとも頻繁な操作を、メニューを開かずに一手でできるように。
- **通知の音を消してチャイムに任せるのは**: 二つ鳴ると騒がしい。チャイムは終わりの種類(上がる二音 = フォーカス終わり、下がる二音 = 休憩終わり)まで伝えられる。

## まだ値を詰めていないもの

| もの | いまの状態 |
| --- | --- |
| 沈む 1.4 秒・消える 2.6 秒 | 方向の理由はあるが、値は目で合わせただけ。実際に使って詰める |

## 理由が弱く、外したもの

書き出してみて理由を言い切れず、外したもの。同じものを戻すときは、ここにある弱さへの答えを先に用意すること。

| もの | 外した理由 |
| --- | --- |
| 上の帯の「ミニタイマー」 | めったに使わない機能が一等地を占めていた。入口はメニューバーにある |
| タスク入力欄の「追加」ボタン | Enter で足せる |
| 下の操作案内(Space / N) | 一度覚えたら読まないのに常に出ていた。最初の案内とボタンの説明へ移した |
| 流れるテープ(目盛り・残り分の数字) | 上の数字と同じ情報を繰り返していた。経過の線一本に置き換えた |
| 各タスクの累計時間 | 「いま選ぶ」判断に使わず、ふりかえりのタスクごとと重複していた |
| 傾向の連続日数 | ゲーム的な仕掛けで、道具の価値観と合わない |
| 「今日」の見出しから、ふりかえりへの移動 | 押せることが見た目からわからなかった。入口はタブに一本化した |
